# BCK Enterprise Backup — встановлення та оновлення

Корпоративна система резервного копіювання та аварійного відновлення інфраструктури (Veeam / Nakivo alternative), написана на **Rust**.

Повний стек компонентів в одному рішенні:
- **`bckd`** — центральний системний демон планування та координації завдань
- **`bck-agent`** — високоефективний агент резервного копіювання на хостах
- **`bck`** — CLI-утиліта повнофункціонального адміністрування
- **`bck-proxy`** — захищений проксі-тунель передачі потоків даних
- **Веб-панель** — сучасна консоль моніторингу та керування задачами відновлення

**Підтримувані платформи:** Ubuntu Linux 24.04 / 25.04 / 26.04 (`x86_64`).

---

## Швидке встановлення / оновлення (одна команда)

```bash
curl -fsSL https://raw.githubusercontent.com/ajjs1ajjs/dist/main/apps/bck/install.sh | sudo bash
```

> **Автоматичне оновлення:** та сама команда виконує й оновлення версії. Конфігурації (`/etc/bck`), бази метаданих, налаштування користувачів та збережені сховища бекапів (`/var/lib/bck`) **повністю зберігаються** — замінюються лише виконувані бінарники та веб-інтерфейс.

### Встановлення конкретної версії

```bash
BCK_VERSION=0.10.10 curl -fsSL https://raw.githubusercontent.com/ajjs1ajjs/dist/main/apps/bck/install.sh | sudo bash
```

## Ключові можливості

| Напрямок | Можливості |
|---|---|
| **Двигун бекапів** | Потоковий сканер → chunker (XXH3) → дедуплікація (SHA-256) → стиснення (LZ4/Zstd) → шифрування (AES-256-GCM / ChaCha20-Poly1305) |
| **Сховища (Storage)** | Локальні диски, S3-сумісні сховища (SigV4, MinIO, AWS), Azure Blob, Google Cloud Storage, Tape (LTFS) |
| **Віртуалізація** | VMware vSphere & Hyper-V: підтримка changed-block tracking (CBT/RCT), миттєве відновлення (Instant Recovery через NFS/iSCSI) |
| **Хмара та контейнери** | AWS (EC2/EBS/RDS), Azure (VM/disk/SQL), GCP (GCE/disk), Kubernetes (Persistent Volumes) |
| **Корпоративний захист** | Багаторівневі SOBR-репозиторії, захист від ransomware (S3 Object Lock, Immutability), SureBackup верифікація |
| **Керування доступом** | Аутентифікація JWT + Argon2, корпоративний SSO (OIDC / LDAP), журнал аудиту дій, multi-tenancy |

## Безпека постачання (Supply Chain Security)

1. Скрипт інсталятора автоматично завантажує найновіший реліз із тегом `bck-v*` з хабу `dist`.
2. Перед розпакуванням перевіряється **SHA-256** хеш архіву.
3. Служба реєструється як systemd-сервіс із налаштованим автоперезапуском при збоях та ізоляцією прав доступу.
