# Harness - download

Native Windows AI harness: subscriptions (Claude Max, ChatGPT Plus, Google AI) + API keys
(DeepSeek, Kimi, GLM, Mistral, Grok, OpenRouter, OpenCode Zen, ...) in one app. **Windows 10/11 x64.**

## Download

- [All releases](https://github.com/ajjs1ajjs/dist/releases?q=harness)
- `Harness_0.14.1_x64-setup.exe` - **NSIS installer** (per-user, Start menu shortcut, clean uninstall)
- `Harness_0.14.1_Portable.zip` - **portable** (unzip and run)

Check ``SHA256SUMS.txt`` to verify integrity.

## Updates

The app checks for updates on start (source: ``latest.json`` in this folder via GitHub Pages)
and installs the downloaded setup after SHA-256 verification.

Source code lives in a private repository.
