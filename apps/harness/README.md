# Harness — завантаження

Нативний Windows-застосунок та AI-оркестратор (Rust + MSVC + eframe). Єдиний десктопний клієнт для роботи з провідними AI-моделями та провайдерами під **Windows 10/11 · x64**.

---

## Завантажити

- [⬇️ Усі релізи Harness](https://github.com/ajjs1ajjs/dist/releases?q=harness)
- `Harness_0.20.2_x64-setup.exe` — **NSIS-інсталятор** (встановлення per-user у `%LOCALAPPDATA%`, ярлик у меню «Пуск», коректне видалення).
- `Harness_0.20.2_Portable.zip` — **портативна версія** (розпакувати у будь-яку теку й запустити без інсталяції).

Поруч із кожним релізом публікується ``SHA256SUMS.txt`` для перевірки цілісності файлів.

---

## Можливості

- **5 ключових провайдерів з коробки**: OpenAI, Anthropic Claude, Google Gemini / AI, OpenCode Zen, OpenCode Go (+ сумісність з DeepSeek, Grok, Mistral, OpenRouter).
- **BYOK (Bring Your Own Key)**: усі API-ключі шифруються та зберігаються виключно локально у системному сховищі **Windows Credential Manager** (жодних відправок на сторонні сервери).
- **Підтримка Model Context Protocol (MCP)**: виконання локальних інструментів (читання, запис, команди терміналу з вікном підтвердження дій).
- **Швидкий та легкий нативний стек**: Rust + eframe, мінімальне споживання ресурсів пам'яті та процесора у порівнянні з Electron-рішеннями.
- **Сучасний робочий простір**: швидкий пікер моделей, менеджери сесій у SQLite, підтримка розмітки коду та гарячих клавіш (`Ctrl+N`, `Ctrl+K`).

## Перевірка цілісності (SHA-256)

Перевірка хешу завантаженого інсталятора у PowerShell:

```powershell
(Get-FileHash .\Harness_*_x64-setup.exe -Algorithm SHA256).Hash
```

Звірте отриманий рядок зі значенням у файлі ``SHA256SUMS.txt`` відповідного релізу.

## Оновлення та цифрові підписи

Застосунок перевіряє наявність нових версій при запуску та автоматично пропонує оновлення:
1. **Джерело перевірки**: маніфест [`latest.json`](latest.json) у цій теці (віддається через GitHub Pages).
2. **Підпис каналу оновлень (Ed25519)**: кожен інсталятор підписується відокремленим підписом, а публічний ключ вшитий у бінарник — непідписані файли або підміна версії блокуються на рівні коду.
3. **Authenticode**: виконувані файли підписані сертифікатом IT-Enterprise із міткою точного часу (RFC 3161 Timestamp).

Вихідний код знаходиться у приватному репозиторії.
