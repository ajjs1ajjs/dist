# Sales Proposal Calculator (IT-Enterprise) — завантаження

Застосунок для сейлз-менеджерів та комерційного відділу (Windows 10/11): швидкий
розрахунок серверних ресурсів для комерційних пропозицій (КП) за обраними
ліцензіями модулів з експортом у Excel та PDF. Постачається інсталятором
(Inno Setup) — «Далі → Далі → Готово», права адміністратора не потрібні.

## Завантажити

- [Усі релізи](https://github.com/ajjs1ajjs/dist/releases?q=rescalc)
- Пряме посилання на конкретну версію:
  `https://github.com/ajjs1ajjs/dist/releases/download/rescalc-vX.Y.Z/ResourceCalculator_Setup_vX.Y.Z.exe`

## Перевірка цілісності

Кожен реліз містить `SHA256SUMS.txt`. Перевірка (PowerShell):

```powershell
(Get-FileHash .\ResourceCalculator_Setup_vX.Y.Z.exe -Algorithm SHA256).Hash
```

Порівняйте з файлом релізу. Незбіг — не запускати.

## Оновлення

Застосунок **оновлюється сам**: перевіряє релізи цього репозиторію (тег `rescalc-v*`)
і, якщо є новіша версія, пропонує «⭳ Оновити до vX.Y.Z». Оновлення завантажується
з прогресом і приймається лише після звірки SHA-256 та перевірки
**Authenticode**-підпису за піном відбитка — підміна не пройде.

Ручний шлях: завантажити новий інсталятор і встановити поверх — дані не зачіпаються.

## Підпис

Інсталятор підписаний Authenticode самопідписаним сертифікатом IT-Enterprise.
SmartScreen може попередити (сертифікат не від публічної CA) — це нормально;
довіру несе пін відбитка сертифіката всередині застосунку.
