# Gym Tracker — застосунок

Офлайн-first PWA для тренувань (Svelte 5 + TypeScript + Vite). Працює у браузері та
встановлюється на телефон як звичайний застосунок.

## Відкрити

**https://ajjs1ajjs.github.io/dist/gym/**

- Дані (ваги, тренування, заміри) зберігаються **локально у браузері** (`localStorage`) —
  нікуди не надсилаються.
- Працює офлайн через service worker (PWA). Щоб встановити на телефон: відкрийте посилання
  та оберіть «Додати на головний екран».
- Зібрана збірка лежить у теці [`gym/`](../../gym/) цього репозиторію (її віддає GitHub Pages).

Вихідний код — у приватному репозиторії; тут лише готовий застосунок.
