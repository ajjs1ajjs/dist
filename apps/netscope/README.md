# NetScope Enterprise — завантаження

Портативний нативний десктоп-додаток Windows для топології інфраструктури
(AD/VPN/сайти/підмережі/DC/сервери). Без встановлення Python, офлайн.

---

## Завантажити

- [⬇️ Усі релізи NetScope](https://github.com/ajjs1ajjs/dist/releases?q=netscope)
- ``NetScope-v1.1.1-portable.zip`` — **портативна версія** (розпакувати в будь-яку теку, запуск ``NetScope.exe`` в 1 клік).
- ``NetScope-v1.1.1-update.zip`` — службовий архів **внутрішнього апдейтера** (той самий вміст без обгортки; качається самим застосунком).

Поруч публікується ``SHA256SUMS.txt`` для перевірки цілісності:

```powershell
(Get-FileHash .\NetScope-v1.1.1-portable.zip -Algorithm SHA256).Hash
```

---

## Оновлення та цифрові підписи

Застосунок перевіряє оновлення при старті і ставить їх сам, без токенів:

1. **Джерело перевірки**: маніфест [`latest.json`](latest.json) у цій теці (віддається через GitHub Pages, читається анонімно).
2. **Підпис каналу оновлень (Ed25519)**: zip підписується відокремленим підписом, публічний ключ вшито в exe — непідписані файли або підміна блокуються кодом (fail-closed).
3. **In-place заміна**: апдейтер чекає виходу процесу, розпаковує архів поверх теки програми і запускає новий exe.

Вихідний код знаходиться у приватному репозиторії.
