02 / Опис

Що це

Game Sales Radar — персональний радар знижок і безкоштовних ігор. Він автоматично збирає актуальні пропозиції Steam: роздачі, гарячі знижки від 25% і топи продажів, а також каталог PC Game Pass — нові добавлення та найпопулярніші ігри. Усе це публікується на сайті й у Telegram-каналі, тож пропозиції не треба шукати вручну.

Сайт — статична PWA: встановлюється на телефон чи ПК, працює офлайн завдяки Service Worker, має темну та світлу теми й двомовний інтерфейс. Дані про знижки оновлює шедулер щогодини в публічному репозиторії артефактів, тому свіжі пропозиції з'являються без перезбірки застосунку, а історія сповіщень показує, що саме знайшлося за останні 30 днів.

03 / Як працює

Принцип роботи

01

Збір даних

Щогодини шедулер тягне Steam API та каталог PC Game Pass: роздачі, знижки від 25%, топи продажів, нові й популярні ігри.

02

Публікація

Свіжі deals.json лягають у публічний репозиторій dist, а нові знижки одразу летять у Telegram-канал.

03

Зовнішній тригер

Cloudflare Worker щогодини викликає workflow_dispatch — GitHub schedule стабільно затримується на години.

04

Сайт

Статична PWA читає deals.json і показує стрічку, фільтри, список бажань та історію за 30 днів.

04 / Можливості

Що вміє

  • Пошук за назвою гри з debounce 300 мс
  • Фільтри за категоріями: безкоштовні, знижки, тренди, Game Pass
  • Сортування за ціною, відсотком знижки та назвою
  • Список бажань, що зберігається в localStorage
  • Історія сповіщень за останні 30 днів
  • Темна та світла теми, перемикання одним кліком
  • PWA з офлайн-режимом через Service Worker
  • Двомовний інтерфейс: українська та англійська

06 / Встановлення

Як почати

t.me/salesgamesua · sync dailyВідкрити ↗

Окремої команди немає: сайт ставиться як PWA прямо з браузера.

Відкрити ↗ Telegram-канал ↗

  • Node.js 20+ і npm — для локального запуску
  • Локальне встановлення — лише Ubuntu (scripts/install.sh)
  • CI та деплой працюють на ubuntu-latest у GitHub Actions
  • Білд статичний: для dist/ достатньо будь-якого веб-сервера (nginx, Caddy)
  • Для деплою — секрет PUBLIC_RELEASE_TOKEN із правом repo на ajjs1ajjs/dist
  • Для сповіщень — TELEGRAM_BOT_TOKEN і TELEGRAM_CHAT_ID у секретах репозиторію

Безкоштовно та без реєстрації

Відкрийте застосунок у браузері — він працює офлайн і встановлюється як PWA.
