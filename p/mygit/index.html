02 / Опис

Що це

MyGit — self-hosted Git-платформа для команд, які хочуть тримати код і CI на власному залізі. Git smart HTTP працює через стандартний протокол: clone, push і pull з логіном, паролем або Personal Access Token. Репозиторії — це звичайні bare-репо на диску, тож доступ і бекапи лишаються прозорими.

У комплекті — перегляд коду з blame, Issues, Merge Requests, webhooks, SSH-ключі та рольова модель прав (owner → guest). Фронтенд на Vue 3 вбудовано в один статичний бінарник, тож сервер працює на Ubuntu amd64 і arm64 без залежностей. Пайплайни виконуються на ваших раннерах — Linux, macOS або Windows.

03 / Як працює

Принцип роботи

01

Встановлення і перший акаунт

Одна команда ставить сервер і реєструє systemd-юніт; після відкриття порту 9555 перший зареєстрований акаунт стає власником.

02

Репозиторії та Git

Створюєте репозиторій у веб-UI або форкаєте наявний, далі працюєте звичайним git clone/push через HTTP або SSH.

03

Рев'ю через Merge Requests

Коміти, гілки, теги та blame видно в браузері; зміни проходять через Issues і Merge Requests із рольовими правами.

04

CI на власних раннерах

Додаєте раннер у Admin → Runners і виконуєте згенеровану команду на хості — Linux, macOS або Windows.

04 / Можливості

Що вміє

  • Git smart HTTP: clone, push, pull з Basic auth або PAT
  • Репозиторії: створення, fork, видалення — bare-репо на диску
  • Перегляд коду: дерево файлів, blob, raw, blame, гілки, теги
  • Issues з коментарями та станами, Merge Requests із merge
  • Webhooks CRUD, SSH git через системний OpenSSH
  • Користувачі: JWT, SSH-ключі, Personal Access Tokens
  • Рольові права: owner, maintainer, developer, reporter, guest
  • CI-раннери на власних машинах, Linux-раннер збирає всі таргети

06 / Встановлення

Як почати

curl … /apps/mygit/install.sh | sudo bash

Та сама команда оновлює: дані, репозиторії та користувачі зберігаються.

релізи ↗ скрипт інсталяції ↗

  • Ubuntu 24.04, 25.04 або 26.04 (amd64 або arm64)
  • Git на хості — сервер викликає git subprocess
  • Порт 9555 (змінюється через MYGIT_PORT)
  • Ліцензія AK-… або 3-денний Trial — сервер fail-closed
  • Для SSH git — системний OpenSSH на Linux
  • Опційно: TLS-сертифікат або reverse-proxy (Caddy/Nginx)
