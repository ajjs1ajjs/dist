02 / Опис

Що це

Vilno VPN — настільний VPN-клієнт для Windows: завантажує каталог публічних серверів VPN Gate, перевіряє профілі та керує OpenVPN Community через Windows Interactive Service. Для підключення потрібна активна ліцензія: ключ вводиться в налаштуваннях і зберігається в Windows Credential Manager.

Застосунок показує один найкращий сервер на країну, перевіряючи TCP-доступність кандидатів, і вміє автоматично перемикатися на наступні сервери, якщо вибраний не відповів. Після обриву з'єднання автоматичне перепідключення виконує до трьох циклів. Kill Switch і блокування DNS поза VPN — експериментальні опції, вимкнені за замовчуванням.

03 / Як працює

Принцип роботи

01

Встановіть застосунок

Завантажте NSIS-інсталятор із релізів vilno-v* і підтвердьте UAC: інсталятор додає OpenVPN Community та службу, якщо їх ще немає.

02

Активуйте ліцензію

Введіть ключ у налаштуваннях. Ключ зберігається в Windows Credential Manager, а перевірка виконується перед кожним підключенням.

03

Оберіть сервер

У каталозі VPN Gate показано один найкращий сервер на країну; можна вибрати конкретну країну або залишити автоматичний вибір.

04

Підключіться

Натисніть «Підключитися». Якщо сервер не відповів, застосунок спробує наступні доступні сервери з налаштованою кількістю спроб.

04 / Можливості

Що вміє

  • Каталог публічних серверів VPN Gate з фільтром за країною
  • Один найкращий сервер на країну з реальною TCP-перевіркою
  • Автоматичне перепідключення після обриву — до трьох циклів
  • Автоматичний вибір наступного сервера, якщо вибраний не відповів
  • Ліцензійна активація без тріалу; ключ у Windows Credential Manager
  • Світла, темна й системна теми, збереження налаштувань
  • Оновлення з перевіркою підпису Tauri updater через публічний канал dist
  • Експериментальний Kill Switch і ручна перевірка DNS/IPv6
