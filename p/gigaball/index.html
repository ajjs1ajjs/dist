02 / Опис

Що це

Гігам’яч (Gigaball) — безкоштовна 3D-спортивна аркада на сонячній іграшковій арені: дві команди по 5 гравців, матчі по 8 хвилин, біг, стрибки, ривки, удари по бортах, повітряні комбінації, паси та анімований суддя.

У браузері доступний миттєвий матч із 9 ботами без інсталяції. Портативна версія для Windows x64 додає локальний і мережевий мультиплеєр (Create / Join по IP:7777, хост на ПК гравця без зовнішніх серверів). Підтримуються українська та англійська мови.

03 / Як працює

Принцип роботи

01

Оберіть формат

Грайте в браузері з 9 ботами або завантажте Windows x64 ZIP на itch.io для онлайн-гри.

02

Орієнтуйтесь на полі

Ваш гравець позначений жовтим кільцем, міткою ТИ та зіркою на мінікарті.

03

Комбінуйте удари

WASD — рух, Space — стрибок, Shift — ривок, ЛКМ/F — удар, E — пас; доступні тренувальні вправи.

04

Хостіть кімнату

У Windows-версії створіть кімнату на своєму ПК — друзі приєднуються напряму за IP:порт, замінюючи ботів.

04 / Можливості

Що вміє

  • Командна гра 5 на 5 на великій арені (35×52,5) з суддею та мінікартою
  • Браузерний режим з ботами без встановлення (Three.js + Rapier3D)
  • Windows x64 версія з мультиплеєром (Colyseus, прямий хост на ПК гравця)
  • Оригінальна синтезована музика Blue Arena Groove та окремі регулятори гучності
  • Повітряні удари, рикошети від бортів і 2 тренувальні вправи
  • Повна двомовність: українська та англійська (УКР / ENG)

06 / Встановлення

Як почати

У браузері працює одразу на itch.io; для мережевої гри завантажте Windows x64 ZIP зі сторінки itch.io.

Грати / завантажити на itch.io ↗ Хаб завантажень DIST ↗

  • Браузер: сучасний десктопний браузер із WebGL, клавіатура та миша
  • Windows x64: розпакуйте ZIP і запустіть Gigaball.exe (для хостингу через інтернет потрібен доступний TCP 7777)
  • Без телеметрії, без реєстрації та безкоштовно
