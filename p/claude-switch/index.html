02 / Опис

Що це

Claude Switch — легка утиліта для системного трею, яка дозволяє перемикати авторизовані акаунти у десктопному застосунку Claude без повторного входу та кодів на email. Токени залишаються зашифрованими ключем самого Claude (DPAPI на Windows, Keychain на macOS).

Форк версії v0.4.0 з мінімалістичним меню трею (акаунти, додавання, автозапуск, вихід), новою фірмовою іконкою, захищеним IPC екземпляра, бекапом пошкодженого стану та оновленнями з репозиторію ajjs1ajjs/claude-account-switcher.

03 / Як працює

Принцип роботи

01

Додайте акаунти

Натисніть Add account… у треї — поточний вхід збережеться, а Claude відкриється для входу в інший акаунт.

02

Контролюйте ліміти в треї

Іконка-кільце в треї показує заповнення 5-годинного ліміту, а меню — живі 5h і тижневі відсотки для всіх акаунтів.

03

Перемикайтесь в один клік

Оберіть інший акаунт у меню: Claude коректно закриється, збереже/відновить сесію, перенесе чати й проєкти та відкриється знову.

04

Продовжуйте зупинені чати

Якщо під час перемикання тривала відповідь у Claude Code, діалог запропонує автоматично продовжити її на новому акаунті.

04 / Можливості

Що вміє

  • Один клік для перемикання акаунтів без кодів підтвердження на пошту
  • Перенесення списку чатів Claude Code і проєктів (spaces) між акаунтами
  • Живі 5-годинні та тижневі ліміти для кожного збереженого акаунта + кільце-індикатор у треї
  • Діалог продовження перерваних чатів після перезапуску Claude
  • Токени не розшифровуються на диск і надсилаються лише в api.anthropic.com
  • Відкритий код (Apache 2.0), автономний бінарник із SHA-256 автооновленням
