02 / Опис

Що це

DiskCleaner — портативна програма для чистки диска C: на Windows. Один .exe без встановлення: темне вікно, галочки з розмірами, кнопка очистки з підтвердженням і шукач великих папок. Прибирає тимчасові файли, кеші Windows, браузерів і NVIDIA, логи, дев-кеші та кошик.

Пункти з позначкою «потрібен адмін» мають кнопку перезапуску з правами адміністратора. Агресивні варіанти — Windows.old, Prefetch, Go module cache — вимкнені за замовчуванням, а заблоковані системою файли просто пропускаються й рахуються окремо. Застосунок оновлюється сам: звіряє SHA-256 і приймає лише збірки з валідним Authenticode-підписом за піном відбитка.

03 / Як працює

Принцип роботи

01

Запустіть exe

Завантажте DiskCleaner.exe з релізів, звірте SHA-256 із SHA256SUMS.txt і відкрийте подвійним кліком — встановлення не потрібне.

02

Виберіть категорії

Галочки згруповані за темами — система, NVIDIA, логи, браузери, дев-кеші, AI-кеші, кеші програм — і показують обсяг.

03

Скануйте й очищайте

Сканування показує результати по категоріях із розмірами, а видалення відбувається лише після підтвердження з показом обсягу.

04

За потреби — як адмін

Для кешу оновлень Windows, логів CBS і звітів WER потрібні права адміністратора — скористайтеся кнопкою «Перезапустити як адмін».

04 / Можливості

Що вміє

  • Один portable .exe — запуск без встановлення
  • Категорії з галочками й розмірами: система, NVIDIA, логи, браузери
  • Дев-кеші: uv, npm, Go build, NuGet, pip, Go module cache
  • AI-кеші: старі VS Code сервери, codex рантайми, файли opencode
  • Шукач великих папок для пошуку зайвого місця
  • Видалення лише з підтвердженням і показом обсягу
  • Самооновлення з перевіркою SHA-256 і Authenticode за піном
  • Не чіпає opencode.db, AI-модель на 4 ГБ і встановлені програми

06 / Встановлення

Як почати

DiskCleaner.exeзавантажити

Один .exe — завантажте з релізів diskcleaner-v* і запустіть

релізи ↗ як встановити ↗

  • Windows 10 або 11
  • Права адміністратора — лише для частини категорій (кеш оновлень, логи CBS, звіти WER)
  • Оновлення приймаються лише за збігом SHA-256 і валідного Authenticode-підпису
  • SmartScreen може показати попередження — сертифікат самопідписаний, довіру несе пін відбитка
  • Запуск із вихідників: Python із залежностями з requirements.lock, далі python app.py
