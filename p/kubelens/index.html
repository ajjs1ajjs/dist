02 / Опис

Що це

KubeLens — настільний Kubernetes IDE для розробників і платформних інженерів, яким потрібен чіткий локальний робочий процес без важкої браузерної панелі керування. Застосунок побудований на Tauri 2, читає ресурси кластера через Kubernetes watch API й оновлює дані в реальному часі. Без акаунта й телеметрії — лише ваш kubeconfig.

Застосунок веде кілька kubeconfig одночасно: записи можна перейменовувати й швидко перемикатися між кластерами. Звідси ж доступні стрім логів із вибором контейнера, інтерактивний shell, port-forward на localhost, метрики CPU та пам'яті, релізи Helm зі значеннями й маніфестами, топологія залежностей і редагування YAML із валідацією. Інтерфейс — англійською та українською; оновлення ставляться всередині застосунку лише з валідним minisign-підписом.

03 / Як працює

Принцип роботи

01

Підключіть кластер

Застосунок бере kubeconfig зі стандартного шляху, тож записи можна перейменовувати й тримати кілька кластерів одночасно.

02

Огляньте ворклоади

Ворклоади — Pods, Deployments, Services, CRDs, RBAC, Nodes — оновлюються в реальному часі через Kubernetes watch API.

03

Логи, термінал, мережа

Стрімте логи з вибором контейнера, відкривайте shell у контейнері та форвардьте порти pod на localhost.

04

Helm, топологія, YAML

Переглядайте Helm-релізи зі значеннями й маніфестами, досліджуйте топологію залежностей і застосовуйте YAML-маніфести, відредаговані з валідацією.

04 / Можливості

Що вміє

  • Мультикластерні kubeconfig: швидке перемикання й перейменування записів
  • Оновлення ресурсів у реальному часі через Kubernetes watch API
  • Стрім логів pod: follow-режим і вибір контейнера
  • Інтерактивний shell у контейнері та port-forward на localhost
  • Метрики CPU та пам'яті для вузлів і pod
  • Helm: релізи, значення, маніфести, notes і ревізії
  • YAML: перегляд, редагування й apply із валідацією
  • Топологія залежностей ворклоадів із drill-down навігацією

06 / Встановлення

Як почати

KubeLens_0.3.41_x64-setup.exeзавантажити

Інсталятор NSIS (.exe) з авто-оновленням — завантажте з релізів kubelens-v*

релізи ↗ як встановити ↗

  • Windows 10 або новіша (64-bit)
  • Kubeconfig із доступом до кластера Kubernetes
  • Мережева доступність kube-apiserver із вашої машини
  • Права в кластері визначає ваш RBAC — застосунок не створює окремих акаунтів
  • Для збірки з вихідників: Node.js 22+, Rust stable (MSVC) і VS Build Tools із C++ workload
