02 / Опис

Що це

Codex Switch — десктопна утиліта для перемикання особистих, робочих і клієнтських акаунтів у Codex Desktop без команд у терміналі чи редагування auth.json. Програма додає акаунти через браузер, стежить за 5-годинними та тижневими лімітами й підтверджує кожне перемикання.

Форк v0.1.28 отримав нову іконку, спрощений інтерфейс без експериментального візуального шуму (прибрано зайві блоки прогнозу та автоскидання) і перевірку оновлень із репозиторію ajjs1ajjs/codex-account-switcher.

03 / Як працює

Принцип роботи

01

Додайте профілі

Відкрийте Manage та пройдіть вхід у браузері — кожен профіль зберігається ізольовано локально.

02

Відстежуйте ліміти

Переглядайте 5-годинну та тижневу шкалу залишку й час скидання прямо у вікні або в треї.

03

Підтвердьте перемикання

Оберіть потрібний акаунт: Codex Desktop коректно завершується, підмінюються облікові дані та застосунок перезапускається.

04

Синхронізація без зайвого

CLI-сесії в інших шляхах лишаються недоторканими, а мінімальні налаштування містять лише потрібні параметри.

04 / Можливості

Що вміє

  • Перемикання акаунтів Codex Desktop на Windows 10/11 і macOS 14+ (Apple Silicon)
  • Очищений мінімалістичний інтерфейс: лише акаунти, шкали 5h/weekly та керування
  • Відсоток залишку ліміту прямо на іконці в треї / menu bar
  • Безпечне завершення активного Codex Desktop і перевірка ідентичності після запуску
  • Самодостатній Windows .exe із вбудованим Swift runtime (не потребує окремих SDK)
  • Відкритий код (MIT), оновлення з репозиторію ajjs1ajjs/codex-account-switcher
