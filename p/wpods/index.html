02 / Опис

Що це

WPods — безкоштовна open-source утиліта для Windows 11, яка додає повноцінну підтримку AirPods: спливаюче вікно заряду навушників і кейса, виявлення в вусі, перемикання режимів шумопоглинання (ANC / Прозорість / Адаптивний), режим низької затримки для ігор і стереозвук навіть при ввімкненому мікрофоні.

Цей форк (v0.3.3) виправляє роботу на вбудованих комбінованих адаптерах MediaTek Bluetooth MT7921 без вимкнення Secure Boot чи переведення Windows у Test Mode, а також переводить канал оновлень на репозиторій ajjs1ajjs/wpods.

03 / Як працює

Принцип роботи

01

Завантажте інсталятор

Скачайте WPods-Setup.exe (v0.3.3) із GitHub Releases і перевірте SHA256SUMS.txt.

02

Встановіть службу

Один інсталятор Inno Setup ставить WPods, сервіс фонової роботи та необхідні компоненти без Test Mode.

03

Відкрийте кейс AirPods

Підключіть навушники в Windows або натисніть Connect у спливаючому вікні в кутку екрана.

04

Керуйте звуком і ANC

Перемикайте шумопоглинання, мікрофонні моделі (DeepFilterNet / RNNoise) та жести натискання.

04 / Можливості

Що вміє

  • Спливаюче вікно як на iPhone із зарядом лівого, правого навушника та кейса
  • Шумопоглинання, Прозорість, Адаптивний режим і виявлення в вусі
  • Стереозвук A2DP разом із працюючим мікрофоном (локальне шумопоглинання голосу)
  • Фікс вбудованих адаптерів MediaTek Bluetooth MT7921 (WinUsb + RadioLink)
  • Не потребує Test Mode чи вимкнення Secure Boot
  • Відкритий код (GPL-3.0), безкоштовно, без телеметрії
